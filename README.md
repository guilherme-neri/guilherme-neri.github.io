# guilherme-neri.github.io

Source for my personal site: <https://guilherme-neri.github.io>

A single static page — no build step, no dependencies. GitHub Pages serves
`index.html` directly.

- `index.html` — the page
- `style.css` — all styling; layout, type and colour knobs are CSS custom
  properties in `:root`
- `papers/` — working paper PDFs
- `images/` — headshot
